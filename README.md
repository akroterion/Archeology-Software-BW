# Archeology-Software-BW

A collection of Python tools for archaeologists working in Baden-Württemberg.

---

## Modules

| Folder | Description |
|--------|-------------|
| [Profiles-BW](Profiles-BW/) | Cross-section visualisation from total-station survey data |
| [Drone-overlay](Drone-overlay/) | Overlay georeferenced drone photos on a total-station plan with automatic feature labels |
